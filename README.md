# 時間割管理アプリ — Timetable Manager

学級担任・教科担任のための週間時間割管理Webアプリです。インストール不要でブラウザから利用でき、データはすべてローカルファイルに保存されます。

**最新実装**: v90 — **未検証**
**暫定安定版**: v89（タグ: `stable-v89`）
**更新日**: 2026年5月  
**対象**: 小学校・中学校・高等学校の教員（教科担任・学級担任）

> **安定版の扱い**: 暫定安定版は v89（タグ `stable-v89`）です。学期設定ダイアログのタブUI化・適用範囲＋個別変更(override)保持トグル・英語辞書の整備までを含む検証済み安定版です。（旧安定版: v84 / タグ `stable-v84`）

## 特徴

- **ブラウザのみで動作** — サーバー不要。インターネット接続がなくても使用できます（初回ロード後）。
- **プライバシー保護** — データはすべてローカルに保存され、サーバーへのアップロードは一切行いません。
- **2つの使用モード** — 学級担任向けの「学級担任モード」と、複数クラスを担当する「教科担任モード」を選択できます。
- **週間グリッド表示** — 曜日×時限のグリッドで授業コマを視覚的に管理します。
- **変更履歴の管理** — 授業変更・振替・クラス交換などの操作を履歴として記録し、いつでも確認・取り消しができます。
- **ドラッグ＆ドロップ** — コマをドラッグして別のコマと直感的に入れ替えられます。
- **Excel・PDF出力** — 週間時間割をExcelまたはPDFで出力できます。
- **Google Drive同期** — Googleアカウントでログインし、隠しフォルダ（appDataFolder）に自動バックアップ・復元ができます。
- **Googleカレンダー連携** — 授業コマをGoogleカレンダーに直接追加・削除できます。ICS形式でのダウンロードにも対応しています。
- **言語切替（段階実装）** — 左下メニューから日本語/英語を切り替えられます。v78時点ではサイドバー、上部操作ボタン、週間グリッド、自動復元、変更確認、学期タブ、統計・履歴・適用ログまで対応中です。
- **パッチインポート** — JSONファイルで一括変更を適用できます（運動会・遠足などの行事対応に便利）。
- **学年・教科カラー設定** — 学年・教科ごとに色を設定して視覚的に区別できます。

## クイックスタート

### 1. アプリを開く

ブラウザで以下のURLにアクセスします。

```
https://timetableapp-ee4m7qag.manus.space
```

または、ローカルで開発サーバーを起動する場合は [ローカルでの開発・ビルド](#ローカルでの開発ビルド) を参照してください。

### 2. 新規時間割を作成する

左サイドバーの **「新規作成」** ボタンをクリックすると、5ステップのウィザードが開きます。

| ステップ | 設定内容 |
|----------|----------|
| Step 1 | 学校名・学校種別・学期制・年度・学期・使用モード・クラス構成 |
| Step 2 | 始業式・終業式の日付、土日授業の有無 |
| Step 3 | 基本時間割（各コマのクラスまたはON/OFF） |
| Step 4 | 教科設定（学級担任モードのみ） |
| Step 5 | 確認・作成 |

**Step 1のポイント:**
- **学校種別**（小学校・中学校・高等学校）を選ぶと、デフォルトの学年数が自動設定されます。
- **クラス構成**で学年ごとのクラス数を設定します。「各3組」などの一括設定ボタンも使えます。
- **使用モード**は後から「設定」ダイアログで変更できます。

**Step 3のポイント（学級担任モード）:**
- 各コマをクリックして「授業あり（ON）」「授業なし（OFF）」を切り替えます。
- コマ右端の **`∨`** ボタンで、そのコマだけ別のクラスに変更できます（学年全体担当などに対応）。

### 3. 週間グリッドで編集する

作成後は週間グリッドが表示されます。各コマをクリックすると右側にインスペクターが開き、以下の操作ができます。

| 操作 | 説明 |
|------|------|
| 授業変更 | クラスや教科を変更します |
| 削除 | そのコマの授業を削除します |
| 移動 | 別の日時に移動します |
| 交換 | 別のコマと入れ替えます |
| 理由の記録 | 変更理由をメモできます |
| 教科設定 | 教科を設定・変更します |

### 4. ファイルを保存する

ツールバーの **「保存」** ボタンをクリックすると、`.timetable` 形式のファイルがダウンロードされます。次回以降は **「ファイルを開く」** からこのファイルを読み込んでください。

> **自動保存について**: 変更は2秒後にブラウザのlocalStorageへ自動保存されます。次回起動時に復元確認ダイアログが表示されます。ただし、ブラウザのキャッシュをクリアするとデータが失われるため、定期的に `.timetable` ファイルとして保存することを強く推奨します。

## 使用モードの選び方

### 学級担任モード（`homeroom`）

担任クラスを固定し、各コマに**教科名**を表示するモードです。

- 担任クラスが自動的に全コマに割り当てられます。
- 各コマ右端の **`∨`** ボタンをクリックすると、そのコマだけ別のクラスに変更できます（学年全体担当・他クラスへの出張授業などに対応）。
- 教科設定（Step 4）で各コマに教科名を割り当てると、週間グリッドに教科名が大きく表示されます。
- 「クラス別集計」タブでは教科ごとの授業コマ数を集計できます。

**こんな先生に向いています:** 小学校の担任で、自分のクラスの時間割を管理したい先生。

### 教科担任モード（`single_subject` / `multi_subject`）

複数のクラスを担当する教科担任向けのモードです。

- 各コマに担当クラスを割り当てます。
- 担当教科を1つ設定すると全コマに自動適用（`single_subject`）、2つ以上設定するとコマごとに教科を選択できます（`multi_subject`）。
- 「クラス別集計」タブでクラスごとの授業コマ数を確認できます。

**こんな先生に向いています:** 音楽・理科・美術などの専科教員で、複数クラスを担当する先生。

## 基本操作ガイド

### 週の移動

左サイドバーの **`<`** / **`>`** ボタンで前後の週に移動します。「今週」ボタンで現在の週に戻ります。「日付で移動」フィールドに日付を入力して特定の週に移動することもできます。

### 変更の取り消し（Undo）

- ツールバーの **「元に戻す」** ボタンで直前の変更を取り消します。
- 左サイドバーの **「変更履歴」** から、過去のすべての変更を一覧表示し、任意の操作を個別に取り消せます。

### 変更履歴

左サイドバーの **「変更履歴」** をクリックすると、すべての変更操作の一覧が表示されます。各操作の右端の **「元に戻す」** ボタンで個別に取り消しができます。

### 適用ログ

**「適用ログ」** では、パッチインポートで適用された変更の詳細ログを確認できます。

### 学年カラー設定

左サイドバー下部の **「学年カラー設定」** から、学年ごとの表示色を変更できます。

### 教科設定

ツールバーの **「教科設定」** ボタンから、教科の追加・削除・色変更ができます。

### 祝日・休校日の設定

ツールバーの **「設定」** ボタン → 「祝日・休校日」タブから、祝日や休校日を設定できます。設定した日は週間グリッドで灰色表示になります。

## ファイルの保存と読み込み

### 保存

ツールバーの **「保存」** ボタンをクリックすると、`.timetable` 形式のファイルがダウンロードされます。

### 読み込み

左サイドバーの **「ファイルを開く」** ボタンをクリックするか、ファイルをドラッグ＆ドロップして読み込みます。対応形式は以下の通りです。

| 形式 | 説明 |
|------|------|
| `.timetable` | アプリのネイティブ保存形式（推奨） |
| `.zip` | 旧形式（後方互換） |

### ファイル形式の詳細

`.timetable` はJSON形式のファイルです。

```json
{
  "format": "timetable-app/v1",
  "version": "1.0",
  "meta": {
    "title": "2025年度 1学期",
    "school": "○○小学校",
    "year": "2025年度",
    "mode": "homeroom"
  },
  "base": [ ... ],
  "ops": [ ... ],
  "subjects": [ ... ]
}
```

| フィールド | 説明 |
|-----------|------|
| `meta.mode` | `"homeroom"` / `"single_subject"` / `"multi_subject"` |
| `base` | 学期全体の基本時間割エントリ（日付×時限×クラス） |
| `ops` | 変更操作の履歴（授業変更・削除・移動・交換） |
| `subjects` | 教科リスト（名前・略称・色） |

## パッチインポート機能

行事や特別日程による一括変更を、JSONファイルで適用できます。ツールバーの **「パッチインポート」** ボタンから開き、「テンプレートをコピー」でJSONのひな形を取得できます。

### 部分変更テンプレート（例）

```json
{
  "format": "timetable-patch/v1",
  "mode": "partial",
  "dateRange": { "start": "2025-09-01", "end": "2025-09-30" },
  "ops": [
    {
      "op": "set_period_class",
      "date": "2025-09-09",
      "period": 1,
      "class": "1年1組",
      "subject": "体育",
      "reason": "運動会練習"
    },
    {
      "op": "delete_period",
      "date": "2025-09-10",
      "period": 3,
      "class": "2年1組",
      "reason": "振替休日"
    }
  ]
}
```

### 対応する操作（op）

| op | 必須フィールド | 説明 |
|----|--------------|------|
| `set_period_class` | date, period, class | 指定コマにクラスを割り当て（`subject`で教科名も指定可） |
| `delete_period` | date, period, class | 指定コマの授業を削除 |
| `set_subject` | date, period, class, subject | 指定コマの教科のみ変更 |
| `move_period` | date, period, class, dst_date, dst_period | 指定コマを別日時に移動 |
| `swap_periods` | date, period, class, dst_date, dst_period | 2コマを入れ替え |

### パッチモード

| モード | 説明 |
|--------|------|
| `partial` | 指定した操作のみ追加・上書き（既存の変更は保持） |
| `full_replace` | 指定した日付範囲の変更をすべてリセットし、新しい操作で置き換え |

## データモデル（技術情報）

### PeriodSlot（1コマ分）

```typescript
interface PeriodSlot {
  period: number;          // 時限番号 (1〜6)
  class: string | null;    // クラス名（例: "4年1組"）
  subject?: string | null; // 教科名（例: "理科"）
  reason?: string;         // 変更理由
}
```

### OverrideOp（変更操作）

```typescript
interface OverrideOp {
  id: string;              // 操作ID（nanoid）
  op: OverrideOpType;      // 操作種別
  date: string;            // YYYY-MM-DD
  period?: number;         // 時限番号
  class?: string | null;   // クラス名
  subject?: string | null; // 教科名
  reason?: string;         // 変更理由
}
```

**演算モデル**: `base[]` + `ops[]` → `effective[]`（`applyOverrides`関数で計算）

## よくある質問

**Q. データはどこに保存されますか？**

A. データはすべてローカルファイル（`.timetable`形式）とブラウザのlocalStorageに保存されます。サーバーへのアップロードは一切行いません。

**Q. 前回のデータを引き続き使うには？**

A. 「ファイルを開く」から前回保存した `.timetable` ファイルを選択してください。ブラウザを閉じても、localStorageに自動保存されたデータが次回起動時に復元されます。

**Q. 複数の学期を管理できますか？**

A. 現在は1ファイル1学期の管理です。学期ごとに別ファイルを作成してください。

**Q. 旧ZIP形式のファイルは読み込めますか？**

A. 「ファイルを開く」からZIPファイルを選択すると、旧形式からの変換読み込みを試みます。

**Q. 印刷するとレイアウトが崩れます。**

A. 「エクスポート → PDF」または「印刷プレビュー」機能をご利用ください。ブラウザの印刷機能を直接使用する場合は、印刷設定で「背景のグラフィック」を有効にしてください。

**Q. スマートフォンでも使えますか？**

A. 基本的な閲覧は可能ですが、グリッドの編集操作はPC環境を推奨します。

**Q. 学級担任モードで、一部のコマを別のクラスに設定するには？**

A. Step 3（授業コマ設定）で、変更したいコマ右端の **`∨`** ボタンをクリックし、ドロップダウンから別のクラスを選択してください。
