# 時間割管理アプリ — README

**バージョン**: v22（2026年2月）  
**対象**: 小学校・中学校・高等学校の教員（教科担任・学級担任）

---

## 概要

週間時間割をブラウザ上で管理するWebアプリです。授業の追加・削除・移動・交換をUIで安全に操作でき、変更履歴（override JSON）から常に最新の時間割を再構築します。データはすべてブラウザのローカルストレージと `.timetable` ファイルに保存されます。サーバーへのデータ送信は一切ありません。

---

## 主な機能

| 機能 | 説明 |
|------|------|
| 週間グリッド表示 | 月〜金（土日授業にも対応）× 1〜6限のグリッドで授業を一覧表示 |
| 授業変更操作 | 削除・追加・移動・交換・理由設定・教科設定の6種類 |
| ドラッグ＆ドロップ | コマをドラッグして別のコマと交換 |
| Undo / Redo | 変更履歴から任意の操作を取り消し・やり直し |
| クラス別集計 | 学期全体のクラス別授業コマ数を集計 |
| エクスポート | Excel（.xlsx）・PDF の2形式でエクスポート |
| パッチインポート | JSON形式のパッチファイルで一括変更をインポート |
| 複数学期管理 | 1ファイルに複数学期のデータを格納 |
| 祝日・休校日管理 | 祝日・休校日を設定し、該当日の授業を自動的に空きにする |
| 学年カラー | 学年ごとに色を設定（4年=エメラルド、5年=ブルー、6年=バイオレット など） |
| 教科カラー | 教科ごとに色を設定（国語=赤、算数=青 など） |
| 自動保存 | 変更から2秒後にlocalStorageへ自動保存 |

## 使用モード

アプリには3種類のモードがあります。新規作成時に選択します。

### 教科担任モード（`single_subject`）
複数クラスを担当する教科担任向けのモードです。各コマに「どのクラスが来るか」を割り当てます。クラス名が主表示となり、学年カラーで色分けされます。担当教科が1つの場合に最適です。

### 複数教科担任モード（`multi_subject`）
複数クラス・複数教科を担当する専科教員向けのモードです。各コマにクラスと教科の両方を設定できます。「クラスメイン」「教科メイン」の表示切り替えボタンで、どちらを大きく表示するかを切り替えられます。

### 学級担任モード（`homeroom`）
担任クラスを固定し、各コマに「何の教科か」を割り当てるモードです。教科名が主表示となり、教科カラーで色分けされます。

## ファイル形式

### `.timetable`（ネイティブ保存形式）
アプリ独自のJSON形式です。`format: "timetable-app/v1"` で識別されます。`semesters[]` 配列で複数学期を管理します。

```json
{
  "format": "timetable-app/v1",
  "version": "1.0",
  "meta": { "title": "2025年度 1学期", "mode": "single_subject" },
  "subjects": [],
  "semesters": [
    {
      "semester": { "startDate": "2025-04-07", "endDate": "2025-07-18", ... },
      "base": [ ... ],
      "ops": [ ... ]
    }
  ]
}
```

### `timetable-patch/v1`（パッチインポート形式）
外部ツールや一括変更に使用するパッチ形式です。

```json
{
  "format": "timetable-patch/v1",
  "mode": "partial",
  "dateRange": { "start": "2025-06-01", "end": "2025-06-30" },
  "ops": [
    { "op": "set_period_class", "date": "2025-06-02", "period": 3, "class": "5年2組" }
  ]
}
```

詳細は `references/patch_format.md` を参照してください。

## 操作ガイド

### 新規作成
1. サイドバーの「新規作成」をクリック
2. 学校名・学校種別・学期制・年度・学期を設定
3. 使用モードを選択（教科担任 / 学級担任）
4. クラス構成を設定（学年ごとのクラス数）
5. 授業日・基本時間割を設定
6. 「作成」をクリック

### ファイルの保存・読み込み
- **保存**: サイドバーの「保存」ボタン（または `Ctrl+S`）で `.timetable` ファイルをダウンロード
- **読み込み**: サイドバーの「ファイルを開く」でファイルを選択、またはドラッグ＆ドロップ
- **自動保存**: 変更は2秒後にlocalStorageへ自動保存。次回起動時に復元確認ダイアログが表示されます

### 授業の変更
1. グリッド上のコマをクリックして選択
2. 右側のパネルで操作を選択（削除・追加・移動・交換・理由・教科）
3. 必要な情報を入力して「実行」をクリック
4. 確認ダイアログで内容を確認して「確定」

### 変更の取り消し
- サイドバーの「元に戻す」ボタン（または `Ctrl+Z`）で直前の変更を取り消し
- 「変更履歴」タブから任意の変更を選択して取り消し可能

### エクスポート
- **Excel**: 右上の「エクスポート」→「Excel」で週単位のシートを生成
- **PDF**: 右上の「エクスポート」→「PDF」でA4縦/横の時間割PDFを生成

## サンプルデータ

3種類のサンプルデータが付属しています。サイドバーの「サンプルデータを読み込む」から選択できます。

| サンプル名 | モード | 内容 |
|-----------|--------|------|
| 担任モード（2年1組） | 学級担任 | 2年1組の時間割。国語・算数・生活など8教科、6件の変更操作を含む |
| 理科専科（4〜6年） | 教科担任 | 4〜6年10クラスの理科専科時間割。28件の変更操作を含む |
| 音楽・体育専科 | 複数教科担任 | 複数クラス・複数教科の専科時間割。12件の変更操作を含む |

## データモデル（技術情報）

### PeriodSlot（1コマ分）
```typescript
interface PeriodSlot {
  period: number;        // 時限番号 (1〜6)
  class: string | null;  // クラス名（例: "4年1組"）
  subject?: string | null; // 教科名（例: "理科"）
  reason?: string;       // 変更理由
}
```

### OverrideOp（変更操作）
```typescript
interface OverrideOp {
  op: "set_period_class" | "clear_period_class" | "set_period_reason" | "set_day_reason" | "set_period_subject";
  date: string;          // YYYY-MM-DD
  period?: number;
  class?: string | null;
  subject?: string | null;
  reason?: string;
}
```

演算モデル: `base[]` + `ops[]` → `effective[]`（`applyOverrides`関数で計算）

## 技術スタック

- **フロントエンド**: React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui
- **ルーティング**: Wouter
- **ビルドツール**: Vite
- **エクスポート**: ExcelJS（Excel）、jsPDF（PDF）
- **フォント**: NotoSansJP（PDF用、157KBサブセット埋め込み）
- **データ保存**: localStorage + `.timetable`ファイル（JSON）

---

## 既知の制限事項

- PDF/Excelエクスポートはブラウザのメモリに依存するため、学期全体（約200日分）を一度にエクスポートすると時間がかかる場合があります
- PNGエクスポートは未実装です（PDFをAdobe Acrobat等で変換してください）
- モバイルブラウザではドラッグ＆ドロップが動作しない場合があります
