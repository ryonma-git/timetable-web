## 形式A — 大日本図書（理科・算数共通）

**対象**: 大日本図書「たのしい理科」「新しい算数」  
**構造**: 単元ごとに別シート。各シートが 1 単元に対応。  
**ヘッダ行**: `小単元 / 時 / 学習内容 / 主な評価規準例`  
**時 列の読み方**:
- `"1"` → 1コマ（単独期）
- `"2\n3"` → 2コマ（期 2 と 3 をまとめて記述）
- `"2〜4"` → 3コマ（期 2〜4 の範囲）
- 空欄 → 前期の続き説明行（スキップ）
- `"-"` → 発展活動（スキップ）

**パーサーの要点**:
```python
def parse_ji_count(ji_str):
    # 範囲指定: "2〜4" → 3
    m = re.match(r"([0-9]+)\s*[〜~～・-]\s*([0-9]+)", ji_str)
    if m: return int(m.group(2)) - int(m.group(1)) + 1
    # 複数期: "2・3" → 2 (数字の個数)
    nums = [p for p in re.split(r"[・、,\s]+", ji_str) if re.match(r"^[0-9]+$", p)]
    if nums: return len(nums)
    # 単独: "1" → 1
    if re.match(r"^[0-9]+$", ji_str): return 1
    return 0
```

取得ファイル: `dainippon_rika3/4/5/6.xlsx`, `dainippon_sansu3/4/5/6.xlsx`  
出力: `dainippon_rika*.json`, `dainippon_sansu*.json`

## 形式K — 啓林館 算数（上下シートまたは学年シート）

**対象**: 啓林館「わくわく算数」  
**構造**:
- 3・4年: 上期・下期で 2 シート（`3上`, `3下`）
- 5・6年: 年間で 1 シート（`5年`, `6年`）

ヘッダ行: `2学期制 / 3学期制 / 大単元(番号) / (名前) / 小単元(marker) / (名前) / 小見出し / 時 / 頁`  
- `col3` = 大単元番号（数字 or `思/学/復` などの記号）  
- `col4` = 大単元名  
- `col7` = 小見出し（= 授業内の活動名、1行 = 1コマ相当）

除外する小見出し: `たしかめよう`, `ふりかえろう`, `やってみよう`, `（小単元とびら）`  
除外する大単元: `巻頭`, `算数のとびら`, `学びのサポート`

取得ファイル: `keirinkan_sansu3/4/5/6.xlsx`  
出力: `keirinkan_sansu*.json`
