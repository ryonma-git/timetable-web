# 指導計画 テンプレート取り込み機能 — 詳細設計

> ステータス: **P1・P2・P3 実装済み**（feature/teaching-plan-templates ブランチ）
> 関連既存実装: 指導計画Excel往復（v91, `lib/teachingPlanExcel.ts`）

---

## 1. 目的・ゴール

先生が**指導計画を毎時間ゼロから手入力する負担をなくす**こと。
理想は「教科書会社の年間指導計画を、設定でポチッと選べば単元と各時間の内容が入る」状態。

## 2. なぜ「各社サイトからの全自動Web取得」を採らないか（重要）

| 論点 | 内容 |
|---|---|
| 著作権 | 各社の年間指導計画は**著作物**。許諾なしの取得・再配布・アプリ同梱は不可 |
| アクセス制御 | 多くが**教師登録制ページ**の奥にあり、自動取得は規約違反になりやすい |
| 技術的脆さ | 公開URL・ファイル形式が各社バラバラで頻繁に変わる。**統一APIなし**＝壊れ続ける |
| 保守コスト | 社×学年×教科×年度の組合せを追従し続けるのは非現実的 |

→ **目的（手入力ゼロ化）は、合法かつ堅牢な「テンプレート・ライブラリ方式」で達成する。**

## 3. 全体アーキテクチャ

```
┌─────────────────────────────────────────────┐
│ 指導計画テンプレート・ライブラリ                  │
│                                               │
│  (A) 内蔵テンプレート                           │
│      学習指導要領ベース（政府・無料・合法）         │
│      public/templates/teaching/*.json          │
│                                               │
│  (B) 取り込みテンプレート                         │
│      先生が各社サイトからDLしたファイルを解析       │
│      （v91のExcel往復を各社フォーマット対応に拡張） │
│                                               │
│        ↓ どちらも同じ内部形式に正規化              │
│                                               │
│  TeachingPlanTemplate { source, grade, subject, │
│                         year, units[], lessons[] }│
│                                               │
│        ↓ 「適用」                               │
│                                               │
│  既存の GradeSubjectPlan にマージ                 │
└─────────────────────────────────────────────┘
```

ポイント: (A)と(B)は**入口が違うだけで、内部形式・適用ロジックは共通**。まず器を作れば後から供給源を足せる。

## 4. データモデル

### 4.1 テンプレート（既存 GradeSubjectPlan をほぼ流用）

```ts
interface TeachingPlanTemplate {
  id: string;              // "mext-std|5年|理科|2020" 等
  source: string;          // "標準（学習指導要領ベース）" / "○○出版（先生提供）"
  sourceKind: "builtin" | "imported";
  grade: string;           // "5年"
  subject: string;         // "理科"
  year?: string;           // 改訂年や年度（任意）
  edition?: string;        // 版・コース名（各社オプション対応用、任意）
  totalPlannedPeriods?: number;
  units: TeachingUnit[];   // 既存型を流用（name, plannedPeriods, color, lessons）
  lessons: LessonPlanEntry[]; // 既存型を流用（unitId, content, ...）
  meta?: {
    license?: string;      // 出所・ライセンス表記（内蔵は学習指導要領由来を明記）
    note?: string;
  };
}
```

> 既存 `GradeSubjectPlan` とほぼ同型なので、適用＝ほぼコピーで済む。型の二重管理を避けるため `TeachingUnit` / `LessonPlanEntry` は既存を再利用。

### 4.2 内蔵カタログのインデックス

```
public/templates/teaching/
  index.json                      ← 一覧（軽量・最初に取得）
  mext-std_5_science_2020.json    ← 各テンプレート本体（選択時に取得）
  mext-std_6_science_2020.json
  ...
```

```jsonc
// index.json
{
  "version": 1,
  "sources": [
    { "id": "mext-std", "name": "標準（学習指導要領ベース）", "kind": "builtin" }
  ],
  "templates": [
    { "id": "mext-std_5_science_2020", "source": "mext-std",
      "grade": "5年", "subject": "理科", "year": "2020改訂",
      "units": 6, "periods": 105, "file": "mext-std_5_science_2020.json" }
  ]
}
```

- `index.json` は `BASE_URL` 前置で fetch（v91のサンプル404修正と同じ方式）
- 本体は選択時に遅延ロード（初期表示を軽く）

## 5. 取り込みフロー & UI

指導計画画面の右上（Excelボタンの隣）に **「テンプレートから取り込む」** を追加。

```
[テンプレートから取り込む] クリック
    ↓
┌──────────────────────────────┐
│ 指導計画テンプレートを選ぶ            │
│  出所 : [標準（学習指導要領）▼]       │  ← 将来 各社（先生提供分）も
│  学年 : [5年 ▼]                    │
│  教科 : [理科 ▼]                    │
│  版/コース: [標準 ▼] (各社オプション)  │
│  年度 : [2020改訂 ▼]                │
│  ──────────────────────────  │
│  プレビュー:                        │
│   単元1 植物の発芽と成長 (6)         │
│   　1 発芽に必要な条件を予想する       │
│   　2 実験計画を立てる…              │
│   単元2 …                          │
│  ──────────────────────────  │
│  適用方法:                          │
│   ◉ 空いている所だけ補完（推奨）       │
│   ○ 単元構成を置き換え（内容は手入力を温存）│
│   ○ 全置き換え                      │
│  　[キャンセル]   [この計画に取り込む]   │
└──────────────────────────────┘
```

- 選択は**現在開いている学年×教科の指導計画**に対して行う（学年/教科は自動プリセット、変更も可）
- 「版/コース」は各社のオプション（例：標準コース / 発展コース）を選ぶための拡張枠。内蔵段階では「標準」のみ

## 6. 適用ロジック（マージ方式）

| 方式 | 挙動 | 用途 |
|---|---|---|
| **空欄補完（既定）** | 既存 lessons の `content` が空の行だけテンプレ内容で埋める。単元割当も空きのみ設定 | 既に一部入力済みでも壊さない |
| **単元構成を置換** | units（単元名・コマ数・色）はテンプレで置き換え、各 lesson の `content`（手入力）は位置対応で温存 | 単元だけ整え直したい |
| **全置換** | units も lessons もテンプレで完全上書き | まっさらから入れる |

- ID温存ルールはv91 Excel取り込みと共通（単元名一致で色・ID温存、行位置一致でクラス別進度メモ温存）
- 適用は既存 `upsertTeachingPlan(plan)` を呼ぶだけ（保存・自動同期は既存経路）

## 7. 標準テンプレートの seed 方針（内蔵データ）

- **出所**: 文部科学省「学習指導要領」＋各教科の標準的な単元配列（年間指導計画の“標準形”）。政府公開＝自由に利用可
- **明記**: 各テンプレに「学習指導要領ベースの標準例。各教科書の実際の配列とは異なる場合があります」と注記
- **着手順（提案）**: 需要の高い専科教科から
  1. 理科 5・6年、英語（外国語）5・6年 … 専科で指導計画ニーズ大
  2. 算数・国語 各学年
  3. 社会・理科 3・4年、その他
- 1テンプレ＝単元名＋各時間の内容（v91の英語専科サンプルで作った粒度と同等）

## 8. (B) DLファイル取り込みの拡張設計

- 入口: 同じダイアログに「ファイルから取り込む」タブ。先生が各社サイトでDLした Excel/CSV を選択
- **フォーマット吸収レイヤー**: `parsers/<publisher>.ts` を用意し、各社レイアウト（見出し位置・列対応）を吸収して内部形式へ正規化
- まずは**汎用パーサ**（v91書き出し形式 ＋ 「単元/時/内容」列を持つ一般的な表）を実装。各社個別対応は要望が出た社から追加
- 著作権配慮: アプリは**解析するだけ**で各社データを同梱・再配布しない。先生が自分のために取り込む私的利用の範囲
